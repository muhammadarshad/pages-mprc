Abstract

Transpose as Orientation + Recoverability

Arshad's Transpose is the MPRC proposal for replacing a flat row/column transpose with an operation that preserves circular state, orientation, recoverability, and ring distance. The unit domain remains Z₂₅₆ with origin/singularity at 128, but learning and descent do not take place inside a single 0–255 unit. They take place over the Hilbert carrier HV×N, where the current visual carrier has HV=14,464 states per sample or layer context.

The missing second component is the Accumulation-Differential Identity (ADI): the state is not represented only by a target and a local ring step. Its path structure is captured by an accumulation Λ and a first differential δ₁, from which the remaining coordinate differentials are deterministically generated. This exact recovery structure is what makes the later Identity-2 trace and inverse-recoverability results meaningful.

Critical distinction. Z₂₅₆ is the deterministic state unit. HV×N is the computational search space. ADI supplies the recoverable coordinate structure. MEASURE chooses the destination; ADI movement performs the ring-native navigation toward it.

01 · Ring Unit

One Unit Is 0…255

The basic state unit is one unsigned byte on the ring:

z ∈ Z₂₅₆
origin / singularity = 128
z < 128 : one side of displacement
z > 128 : opposite side of displacement

The interpretation is geometric: distance from 128 and direction around the ring replace an ordinary signed scalar axis. No float or signed-number representation is required for the core state.

02 · Why Ordinary Transpose Is Incomplete

Matrix Tᵀ Forgets Circular Orientation

A conventional transpose exchanges row and column indices. For an MPRC tensor this is insufficient because the entries also carry ordered ring position and orientation. The transpose therefore has to preserve or explicitly invert the traversal relation; otherwise two tensors with identical rectangular layouts but opposite circular orientation become indistinguishable.

transpose = index reorientation + ring-orientation transport + recoverability
03 · Accumulation-Differential Identity

The Missing Right Component

For a sequential N-dimensional state (a₁,…,a_N), ADI uses two observables:

Λ = Σᵢ aᵢ
δ₁ = a₁ − a₂

The remaining differentials are not free variables. Under the odd-increment rule:

δ_k = δ₁ + (k² − 1),   k=2,…,N−1
successive gaps = 3,5,7,9,…

For δ₁=11 this gives 11,14,19,26,35,… . This is the component omitted from the previous draft: ADI is not merely the final stride-inverse closure. It is the accumulation-plus-differential structure that describes the N-dimensional path itself.

04 · Exact Recovery

Two Observables Recover the Whole Path

Given Λ, δ₁, and the odd-increment rule, the coordinate vector is recovered exactly:

a₁ = (Λ + Σ_{k=1}^{N−1} δ_k) / N
a_{k+1} = a₁ − δ_k

The derivation is direct: substituting a_{k+1}=a₁−δ_k into Λ=Σaᵢ gives Λ=Na₁−Σδ_k. The uploaded ADI paper reports 400,500 random reconstruction trials from N=2 through N=256 with zero errors within the stated odd-increment domain.

05 · Minimality

Why Λ and δ₁ Are Both Required

Within the ADI path family, Λ fixes total accumulation and δ₁ fixes the opening differential. Without Λ the scale is undetermined; without δ₁ the differential staircase cannot be generated. No third independent observable is required because every δ_k for k≥2 follows deterministically from δ₁.

minimal state observables = {Λ, δ₁}
06 · Ring-Native ADI

Recovery on Z₂₅₆

For a_i∈Z₂₅₆ the paper defines:

Λ = (Σᵢ aᵢ) mod 256
δ₁ = (a₁ − a₂) mod 256
δ_k = (δ₁ + k² − 1) mod 256

For N=2^k, the proposed ring-native implementation uses a right shift for division by N; for odd N, a modular inverse exists whenever gcd(N,256)=1. The scope remains the specific sequential-navigation/odd-increment family stated in the ADI paper, not arbitrary-vector compression.

07 · Hilbert Volume

Descent Lives in HV × N

For the current vision carrier:

HV = 113 × 128 = 14,464
search domain = HV × N = 14,464 × N

The earlier ADI implementation exposed the important failure mode: navigating descent only over 0–255 confuses the deterministic state alphabet with the computational search space. A byte state already knows how to wrap on Z₂₅₆. What has to be learned is where the interacting state lies across the Hilbert carrier and across N samples, sites, channels, or model states.

09 · Operator Route

BIND · REACT · MEASURE

The learning route uses the GEVHV operator family rather than importing a conventional gradient scale into the ring:

BIND → compose the current state relation
REACT → apply LUT-native activation
MEASURE → compute ring-native discrepancy and target

ADI does not invent the target. MEASURE defines the target relation; ADI supplies the recoverable path geometry and the STEP used to reach it.

10 · Measure Argmin over HV×N

The Target Comes from the Measure

t = argmin_{v ∈ HV×N} E(v)
E(v) = Σ_w Σ_i d_ring(reg[w][i] + v[i], states[w][i])

Once MEASURE has produced t, the descent begins from a seed μ₀ and advances by ADI steps:

μ₀ → μ₁ → μ₂ → … → t
μ_{r+1} = ADI_STEP(μ_r,t)
11 · Exact Ring Closure

No Teleport to the Target

The early solve_byte() prototype contained an invalid escape: if no trial stride improved the measure, it assigned current = target. That proves assignment, not descent. The corrected closure uses the exact inverse of stride 7:

7⁻¹ ≡ 183 (mod 256)
Δ = (t − μ) mod 256
q = Δ · 183 mod 256
7q ≡ Δ (mod 256)
μ' = μ + 7q ≡ t (mod 256)

This is the local ring closure. It must not be mistaken for the complete HV×N descent or for the ADI recovery identity above.

Wave-Native Streaming Cost

14 · What ADI Replaces

STEP Instead of Derivative Scale

Conventional gradient descent requires a derivative direction and a chosen scale such as a learning rate. The MPRC route separates the problem:

ADI (Λ,δ) → recoverable path coordinates
MEASURE → exact target relation over HV×N
ADI_STEP → ring-native navigation / closure

This three-part separation is the right form of the descent: representation, target selection, then movement.

15 · Relation to GEMM/GEMV

From Rectangular Products to Circular Composition

Arshad's Transpose is being developed as part of the broader MPRC kernel route intended to replace or reduce dependence on GEMM, GEMV, IMMA, and conventional gradient descent. The replacement is not claimed merely by renaming matrix multiplication. It requires composition, activation, recoverable path encoding, target selection, and update to be expressed through ring-native operations and then benchmarked against standard kernels.

16 · Circular Reversal

Transpose Must Preserve CW/CCW

A valid circular transpose needs an involution test while preserving ring distance and orientation semantics:

T_circ(T_circ(X)) = X

The exact kernel law implementing that involution remains active proof/implementation work.

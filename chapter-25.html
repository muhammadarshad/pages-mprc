Abstract

An Exact Operator Spine

This chapter formalizes the operator geometry generated by the 8-state Quantinion construction. Seven nonzero directions sit inside an 8×8 operator space. A classical orientation of the seven non-reference states by the residue set {1,2,4} produces 21 directed pair representatives. The trace-zero operator module over Z/(2ᵐ) has free rank 63 and admits the exact decomposition

63 = 14 + 21 + 28 = 56 + 7.

Fourteen reference couplings generate the entire trace-zero module under commutators. The frozen QH4 address simplifies to a mixed-radix equation with coefficients 64,21,7,1, and the local Arshad Transpose becomes an involution on Z₃² whose invariant sectors each contain 21 active states per quadrant. Finally, the canonical tensor lift has kernel exactly {λI : ℓλ=0}; at ℓ=4 over Z₂₅₆ this is the four-state set {0,64I,128I,192I}.

Novelty boundary. The Frobenius group F₂₁ and basic matrix-unit commutator identities are classical. The contribution here is the exact synthesis with the QH4 address, Transpose orbit geometry, dyadic trace-zero module and tensor-lift kernel. No claim is made to have discovered F₂₁.

01 · Eight States

The 8×8 Operator Space

The generator [1,2,4] represents three independent binary coordinates, hence eight subset states. Index them as one reference state ∞ together with seven non-reference states labeled by Z₇. The full matrix operator module has 64 coordinate units E_{ab}.

8 states → 8² = 64 matrix units.
02 · Seven Directions and 21 Pairs

The {1,2,4} Orientation

On Z₇ let Q={1,2,4}. Its negative set is −Q={3,5,6}; together they partition all six nonzero residues. Orient an unordered pair {x,y} by x→y exactly when y−x∈Q. Every pair receives one and only one orientation, so

C(7,2)=21=7×3.

The affine maps x↦ax+b with a∈{1,2,4}, b∈Z₇ form the classical non-abelian Frobenius group of order 21. Multiplication by 2 cycles 1→2→4→1. The integer pair products of [1,2,4] are [2,4,8], which reduce modulo seven to the same order-three cycle [2,4,1].

03 · Trace-Zero Module

Why the Operator Count Is 63

Let R=Z/(2ᵐ). The trace map M₈(R)→R is surjective, so its kernel is a free direct summand of rank 63. An explicit basis consists of 56 off-diagonal units and seven diagonal differences

H_a = E_{aa} − E_{∞∞},   a∈Z₇.
56 + 7 = 63.

Using the {1,2,4} orientation, the same basis splits as

14 reference couplings + 21 forward non-reference edges + (21 reverse edges + 7 H_a)
63 = 14 + 21 + 28.

This is a direct-sum decomposition of R-modules; it is not claimed to be a three-piece Lie grading.

04 · Fourteen Generate Sixty-Three

Commutator Closure

Take only the 14 couplings between the reference state and the seven non-reference states:

E_{a∞}, E_{∞a},   a∈Z₇.

For a≠b,

[E_{a∞},E_{∞b}] = E_{ab}.

For a=b,

[E_{a∞},E_{∞a}] = E_{aa}−E_{∞∞}=H_a.

Thus the 14 reference couplings generate every element of the 63-dimensional trace-zero module under R-linear combinations and commutators.

05 · QH4 Mixed-Radix Form

The Address Coefficients 64,21,7,1

Write the frozen QH4 coordinate γ−1 as

γ−1 = 9θ + 3a + p
θ∈{0,1,2,3},   a,p∈{0,1,2},   σ∈{1,…,7}.

Substitution into the existing active-position formula gives exactly

m = 64θ + 21a + 7p + σ
z = 7m mod 256.

For fixed θ, the term 21a+7p+σ runs through 1,…,63 exactly once. Hence m runs through every non-vacuum position in the four 64-state sectors, and multiplication by the unit 7 preserves bijectivity. The only missing ring states are

{0,64,128,192}.
06 · Local Arshad Transpose

The 3×3 Involution

On the local nine-state coordinate (a,p)∈Z₃² define

T_k(a,p)=(p+k, a−k) mod 3.

Then T_k²=I. The sum coordinate

s=a+p mod 3

is invariant, while the difference j=p−a transforms as

j ↦ −(j+2k) mod 3.

The fixed condition is j=−k. Each T_k therefore has three fixed points and three two-cycles on the nine local states. Multiplying by seven σ values and four θ sectors gives, globally,

84 fixed active states + 84 two-cycles = 252 active states.

Within a single 63-state quadrant the invariant s partitions the state space into three 21-state sectors.

07 · Tensor-Lift Kernel

When Composite Order Forgets a Central State

Let A∈M₈(Z/(2ᵐ)) and define the canonical ℓ-fold operator lift

ρ_ℓ(A)=Σ_{r=1}^{ℓ} I^{⊗(r−1)}⊗A⊗I^{⊗(ℓ−r)}.

Tensor-Lift Kernel Theorem.

ker ρ_ℓ = { λI₈ : ℓλ = 0 mod 2ᵐ }.

Off-diagonal entries cannot cancel because each changes one tensor coordinate in a unique slot. Once A is diagonal, comparing tensor basis states that differ at one position forces all diagonal entries equal. The remaining scalar condition is ℓλ=0.

08 · 64 and 512

Even/Odd Composite Contrast

For Z₂₅₆, the kernel size is gcd(ℓ,256). In particular,

ℓ=2: ker ρ₂={0,128I}
ℓ=3: ker ρ₃={0}
ℓ=4: ker ρ₄={0,64I,128I,192I}.

Thus the 8²=64 pair level loses a central half-turn, while the 8³=512 cubic lift is faithful. At fourth order the central kernel has exactly the same four spacings as the QH4 vacuum set.

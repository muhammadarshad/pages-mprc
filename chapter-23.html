Global Recovery over 2-Power Rings

Abstract

An Overcomplete Cubic with Exact Recovery

This chapter records the Quantinion Simplex Cubic Decomposition Theorem. Let Rₘ=Z/(2ᵐ) and let n≥4 be even. Consider a symmetric cubic tensor

T = Σ_{q=0}^{n} v_q ⊗ v_q ⊗ v_q,   v_q ∈ Rₘⁿ.

If the parity reductions s_q=v_q mod 2 form a binary simplex frame — their sum is zero and any n of the n+1 vectors are independent — then the entire n+1 term decomposition is globally identifiable up to permutation. The recovery is constructive: first recover the parity frame from contraction ranks over F₂, then lift the atoms one bit at a time through Z₄,Z₈,…,Z_{2ᵐ}. For the Quantinion instance (n,m)=(8,8), this gives an exact 9-component decomposition in an 8-dimensional state space over Z₂₅₆.

Scope. The theorem is not a claim about arbitrary tensor decompositions. It applies to the stated simplex-frame cubic family over 2-power rings. The boundaries — even coefficients, odd n, and non-simplex overcomplete families — remain separate problems.

01 · Setting

The Ring and the Cubic

Rₘ = Z / 2ᵐZ
T ∈ Sym³(Rₘⁿ)
T = Σ_{q=0}^{n} v_q^{⊗3}
r = n+1

The decomposition is already overcomplete because r=n+1 exceeds the vector dimension n. In the MPRC/Quantinion specialization, n=8, m=8, r=9 and the observable cubic has 8³=512 ordered entries.

02 · Binary Simplex Frame

The Parity Skeleton

Reduce every atom modulo two:

s_q = v_q mod 2 ∈ F₂ⁿ.

The required frame satisfies

Σ_{q=0}^{n} s_q = 0
every n of {s₀,…,s_n} are linearly independent.

Every such frame is GLₙ(F₂)-equivalent to the canonical form

s₀ = 1 = (1,…,1)
s_i = e_i,   i=1,…,n.

The theorem is proved in canonical coordinates and transported through the invertible binary change of basis.

03 · Observer Contractions

The Tensor Reveals Its Dual Frame

Let T̄=T mod 2. For each nonzero observer x∈F₂ⁿ, contract the first mode:

M_x = T̄(x,·,·).

In canonical coordinates, with w=wt(x),

M_x = diag(x) + (w mod 2) · 11ᵀ
rank(M_x) = w,   w even
rank(M_x) = w+1,   w odd and w<n.

Because n is even, exactly n+1 observers have full rank n: the all-one vector and the n vectors obtained by clearing one coordinate. These form the dual simplex frame.

04 · Global Parity Uniqueness

No Second n+1-Term Parity Decomposition

Suppose the same binary tensor had another n+1-term decomposition T̄=Σ t_q^{⊗3}. Tensor diagonal entries imply Σt_q=0. For every full-rank observer d, the contraction

M_d = Σ_{q:dᵀt_q=1} t_q t_qᵀ

has rank n, so at least n atoms are active. The active count is even because dᵀΣt_q=0. Since n is even and there are only n+1 atoms, exactly n are active: every full-rank observer annihilates exactly one atom and the remaining n atoms form a basis.

Distinct full-rank observers must annihilate distinct atoms. After ordering the observers d₀,…,d_n and stacking them as D, every hidden parity atom obeys

D t_q = 1 + e_q.

The matrix D has column rank n, so each system has one solution. Those solutions are exactly the original simplex atoms. Therefore the n+1-term parity decomposition is globally unique up to permutation.

05 · One-Bit Lift

Cubic Recovery Becomes Linear

Assume the atoms are known modulo 2ᵇ. Write the next lift as

v'_q = v_q + 2ᵇ δ_q,   δ_q ∈ F₂ⁿ.

Modulo 2ᵇ⁺¹, all terms containing two factors of 2ᵇ vanish. Therefore

(v_q+2ᵇδ_q)^{⊗3} ≡ v_q^{⊗3}
+ 2ᵇ(δ_q⊗s_q⊗s_q + s_q⊗δ_q⊗s_q + s_q⊗s_q⊗δ_q)
(mod 2ᵇ⁺¹).

The next bit is therefore obtained from a binary linear system J_S δ = R_b rather than from nonlinear optimization.

06 · Jacobian Injectivity

The Lift Has No Hidden Direction

For the canonical simplex, suppose J_Sδ=0. On a tensor coordinate (i,j,k) with all indices distinct, only the all-one atom contributes, giving

δ₀,i + δ₀,j + δ₀,k = 0.

Because n≥4, comparing triples forces all entries of δ₀ to be equal; substituting back forces that common bit to be zero. Then coordinate (i,i,j) gives δ_i,j=0 for i≠j, and (i,i,i) gives δ_i,i=0. Hence every perturbation vanishes:

ker J_S = {0}
rank J_S = n(n+1).

Each lift is unique.

07 · Main Theorem

Quantinion Simplex Cubic Decomposition Theorem

Theorem. Let n≥4 be even and Rₘ=Z/(2ᵐ). If T=Σ_{q=0}^{n}v_q^{⊗3} and the parity reductions {v_q mod 2} form a binary simplex frame, then any other n+1-term symmetric cubic decomposition of T consists of exactly the same atoms, up to permutation.

Proof structure:

T → T mod 2
→ full-rank contractions
→ unique parity simplex frame
→ unique lift mod 4
→ unique lift mod 8 → … → mod 2ᵐ.
08 · Quantinion Instance

The 8 → 9 → 512 Case

n = 8
m = 8
r = n+1 = 9 = 1+8
Rₘ = Z₂₅₆
T ∈ Z₂₅₆^{8×8×8}
ordered cubic entries = 8³ = 512.

The observer search contains only 2⁸−1=255 nonzero binary observers. Once the nine parity atoms are recovered, seven bit lifts reconstruct all 72 atom coordinates:

2 → 4 → 8 → 16 → 32 → 64 → 128 → 256.
09 · Odd Unit Weights

Weighted Cubics Stay in the Same Class

Consider T=Σ λ_q v_q^{⊗3} with every λ_q odd. The units of Z/(2ᵐ) form a finite 2-group, so the cube map is an automorphism. Each odd λ_q therefore has a unique unit cube root μ_q. Thus

λ_q v_q^{⊗3} = (μ_q v_q)^{⊗3}
μ_q mod 2 = 1.

The parity simplex geometry is unchanged. This matches the MPRC scalar BIND restriction to odd multiplicative units.

The failed statements are retained because they define the boundary of the theorem rather than being edited away after the result was known.

11 · Verification

Independent Regression Checks

A separate exact-integer verifier reconstructs random hidden simplex frames after random GLₙ(F₂) changes of basis and random Z₂₅₆ lifts. The current regression set covers n=4,6,8 and checks the contraction-rank criterion, parity support recovery, full Jacobian rank, and all seven byte-lifting stages. The verification code is published with the formal paper.

12A · Residual-Simplex Extension

The First Solvable r = n+2 Class

The main theorem stops at r=n+1, but a structured n+2 family can also be recovered exactly. Let the parity atoms consist of a binary simplex frame {s₀,…,s_n} plus one residual atom u. Because the simplex frame sums to zero, the diagonal of the parity tensor exposes the residual immediately:

diag(T mod 2) = Σ s_q + u = u.

Subtract u^{⊗3} modulo two and the remaining parity tensor is exactly the simplex cubic of the main theorem. The only remaining issue is whether the n+2 atoms lift uniquely through the 2-power ring.

Residual-Simplex Lift Theorem. In canonical coordinates let U={i:u_i=1}. If |U|≥4 and |Uᶜ|≥3, then the combined one-bit lifting Jacobian for the simplex frame plus u has trivial kernel. Hence the residual-simplex decomposition lifts uniquely through Z₄,Z₈,…,Z_{2ᵐ}.

For the Quantinion case n=8, this leaves exactly Hamming weights 4 and 5. In simplex language the tenth atom is a balanced 4/5 split of the nine simplex vertices. Random hidden-frame Z₂₅₆ regressions recover all 80 byte coordinates exactly.

n=8, r=10: wt(u)∈{4,5} ⇒ rank J = 80/80
wt(u)∈{2,3,6,7} ⇒ rank J = 78/80

The deficient cases are genuinely non-identifiable inside this family: nonzero Jacobian directions already create distinct decompositions modulo four. This is not repaired by later lifting.

Boundary. This extension proves uniqueness within the simplex-plus-one-residual family. It does not prove that an arbitrary unrelated 10-atom family cannot represent the same tensor.
